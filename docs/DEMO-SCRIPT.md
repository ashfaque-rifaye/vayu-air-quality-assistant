# Demo video script (under 4 minutes)

This follows the PromptWars video guide: a walkthrough in the order a user would follow, live typing, success and error cases, GenAI called out on screen, and proof that responses are dynamic.

**Setup:** use the live app at https://vayu-375514827428.asia-south1.run.app (or run `npm run build && npm start` with a `GEMINI_API_KEY` in `.env`), in a fresh browser window with no saved plans, at 110 to 125% zoom so inputs are readable. Keep the cursor visible, and pause for a beat on each result. Captions are shown below, so narration is optional.
